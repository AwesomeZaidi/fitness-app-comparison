# Security policy

This repository holds public data and small scripts that fetch public web pages. It stores no user data and no credentials; the weekly workflow uses only GitHub's built-in `GITHUB_TOKEN`.

If you find a problem anyway — for example a way to make the workflow run untrusted code or publish something it shouldn't — please email **splyt.fit@gmail.com** with "Security" in the subject instead of opening a public issue. You'll get a reply within 3 working days.
